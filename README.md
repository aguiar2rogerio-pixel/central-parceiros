# Central de Parceiros

Landing page estática em português para apresentar a proposta de divulgação do Meu Caixa e do Mercado Inteligente.

## Implantação no Vercel

- Importe este repositório e use a raiz como diretório do projeto.
- Framework preset: **Other**.
- Não há comando de build nem dependências para instalar; o Vercel pode servir os arquivos estáticos diretamente.
- A branch principal é `main`.
- O site não tem backend nem formulário: os contatos abrem WhatsApp, e-mail ou perfis externos.

Antes de divulgar a parceria, complete os trechos `[CONFIGURAR]` e `[CONFIRMAR]` relacionados às condições comerciais, aprovação, rastreamento, pagamento e reembolsos.
